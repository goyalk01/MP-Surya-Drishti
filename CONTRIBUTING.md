# Contributing to MP Surya-Drishti

Thank you for your interest in contributing to **MP Surya-Drishti**! We welcome contributions from developers, researchers, students, and open-source enthusiasts.

---

## 🌟 How Can You Contribute?

You can contribute to MP Surya-Drishti in several ways:

1. **Reporting Bugs**: Open an issue describing the bug, steps to reproduce, and your environment.
2. **Suggesting Features**: Propose new computer vision backbones, dataset loaders, or analytics algorithms.
3. **Submitting Pull Requests**: Implement bug fixes, add unit tests, or extend framework capabilities.
4. **Improving Documentation**: Fix typos, refine docstrings, or add tutorials.

---

## 🚀 Getting Started

1. **Fork the Repository**:
   Click the **Fork** button at the top right of the GitHub page.

2. **Clone your Fork**:
   ```bash
   git clone https://github.com/goyalk01/MP-Surya-Drishti.git
   cd MP-Surya-Drishti
   ```

3. **Set Up Development Environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

4. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```

---

## 📐 Code Style & Guidelines

- **Python Style**: Follow PEP 8 guidelines.
- **Type Hints**: Include type hints for function arguments and return values.
- **Docstrings**: Write Google-style docstrings for classes and public methods.
- **Testing**: Ensure existing unit tests pass before submitting your pull request:
  ```bash
  python -m pytest tests/ -v
  ```

---

## 📥 Submitting a Pull Request

1. Commit your changes with clear, descriptive commit messages:
   ```bash
   git commit -m "feat(models): add DeepLabV3+ architecture plugin"
   ```
2. Push your branch to GitHub:
   ```bash
   git push origin feature/your-feature-name
   ```
3. Open a Pull Request on GitHub targeting the `main` branch.
