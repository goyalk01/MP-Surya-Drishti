# Security Policy

## Supported Versions

The table below specifies the security support status for MP Surya-Drishti releases:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of MP Surya-Drishti seriously. If you believe you have found a security vulnerability in this repository, please report it to us responsibly:

1. **Do NOT open a public GitHub issue.**
2. Email the project maintainers directly with details of the vulnerability.
3. Include detailed steps to reproduce the issue (proof-of-concept script, configuration, or environment details).

### Response Timeline

- **Initial Acknowledgment**: Within 48 hours.
- **Vulnerability Assessment**: Within 5 business days.
- **Fix / Advisory Release**: Target within 14 business days.

Thank you for helping keep MP Surya-Drishti secure for the open-source community!
